# Encoder Simulator – Digital Logic Lab

An interactive web-based simulator that demonstrates the working of **4:2 and 8:3 encoders** using digital logic concepts.

The project allows users to explore encoder block diagrams, understand OR-gate logic, perform interactive simulations, view Boolean expressions, and verify outputs using truth tables.

**Technologies Used:** HTML, CSS, JavaScript.

**Key Features:**
- 4:2 and 8:3 encoder simulation
- Interactive input selection
- Block and logic diagrams
- Real-time binary output
- Boolean expressions
- Encoder truth tables
